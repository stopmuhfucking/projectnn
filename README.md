# КнигаМир — книжный магазин (SQLite + Python/Tkinter + ADO.NET)



```
python db.py      # (необязательно) создать базу заново — файл bookstore.db уже готов
python app.py     # запустить приложение с окнами
```

Нужен Python 3.8+. Все библиотеки стандартные (`sqlite3`, `tkinter`), ничего устанавливать не надо.
На Linux `tkinter` ставится отдельно: `sudo apt install python3-tk`.
Если запустить `app.py` без `bookstore.db`, база создастся сама.


| Роль | Логин / пароль | Что можно |
|---|---|---|
| Читатель | `reader` / `reader123` (или `maria` / `maria123`) | смотреть и искать каталог, класть книги в корзину, оформлять заказ, видеть и отменять (пока «Новый») свои заказы |
| Менеджер | `manager` / `manager123` | всё, что нужно в работе магазина: добавлять и менять книги, продавать в магазине, вести все заказы (менять статус), клиенты, отчёты |
| Владелец | `owner` / `owner123` | полный доступ: всё как у менеджера + удаление книг, журнал действий, сотрудники, резервные копии |

Новый читатель может зарегистрироваться на экране входа (кнопка «Регистрация читателя»).
Пароли в базе хранятся только в виде `соль$SHA-256`. После 3 неверных паролей кнопка «Войти» блокируется на 5 секунд.


| Сущность | Таблица | Поля |
|---|---|---|
| Клиент | `Customers` | ФИО, телефон, email, **адрес доставки** (+ логин и пароль для входа) |
| Заказ | `Orders` | номер (`id`), дата, клиент, статус, сумма |
| Состав заказа | `OrderItems` | заказ, книга, количество, цена (на момент заказа) |

Статусы: Новый → Собран → Отправлен → Доставлен (или Отменён).
Триггеры в БД сами: проверяют остаток, списывают книги, считают сумму заказа, возвращают книги при отмене и не дают «оживить» отменённый заказ.
Заказ создаётся одной транзакцией: если хоть одной книги не хватает, не создаётся ничего.



- `app.log` — технический журнал: запуск, вход и выход, **неудачные попытки входа**, все действия с книгами и заказами, ошибки.
- вкладка «Журнал действий» (только владелец) — то же по действиям пользователей, из таблицы `AuditLog`.


Тот же `bookstore.db` открывает C#-проект. Провайдер `Microsoft.Data.SqlClient` заменён на `Microsoft.Data.Sqlite`. Код почти не меняется:

| SQL Server (было) | SQLite (стало) |
|---|---|
| `Microsoft.Data.SqlClient` | `Microsoft.Data.Sqlite` |
| `SqlConnection`, `SqlCommand`, `SqlDataReader` | `SqliteConnection`, `SqliteCommand`, `SqliteDataReader` |
| `Server=localhost;Database=...;Trusted_Connection=True` | `Data Source=bookstore.db;Foreign Keys=True` |
| `SELECT TOP 10 ...` | `SELECT ... LIMIT 10` |
| `SCOPE_IDENTITY()` | `last_insert_rowid()` |

Запуск: `cd csharp`, затем `dotnet run` (нужен .NET 8 SDK). Меню зависит от роли, вход теми же логинами. Проверка пароля в C# совпадает с Python (SHA-256 с солью).


- `app.py` — окна Tkinter (вход, каталог, корзина, заказы, клиенты, отчёты, журнал, администрирование)
- `repo.py` — доступ к данным (книги, клиенты, сотрудники, заказы)
- `auth.py` — пароли, вход, роли и права · `db.py` — подключение, создание БД, логирование
- `reports.py` — 4 отчёта + экспорт в CSV · `backup.py` — резервные копии и восстановление
- `sql/bookstore.sql` — схема, представления, триггеры · `sql/seed.sql` — тестовые данные
- `test_logic.py` — проверка БД, ролей и заказов без окон (`python test_logic.py`)
- `csharp/` — ADO.NET-проект на SQLite
